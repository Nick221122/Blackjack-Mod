# Build and install

1. Install Java 21.
2. Open a terminal in the repository root.
3. Windows: run `gradlew.bat build`.
4. The production mod JAR will be in `build/libs/`.
5. Put `blackjack-calculator-1.21.11.jar` in the `.minecraft/mods` folder.
6. Use Minecraft Java 1.21.11 with Fabric Loader 0.19.2+ and Fabric API 0.141.6+1.21.11.

The project is client-side only. The server does not need the mod installed.
